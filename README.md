### 🚀 Features

✅ File upload, download, and management
✅ User authentication and authorization
✅ Storage limit checks and management
✅ File metadata retrieval
✅ Inline query support for easy command execution
✅ Customizable bot menu for easy navigation
✅ Logging and error handling for robust operation

---

### 📦 Installation

To set up the bot, follow these steps:

1. Clone the repository: `git clone https://github.com/ripVort3X/VortXtra_bot.git`
2. Install the required packages: `pip install -r requirements.txt`
3. Set up your Telegram bot token and other environment variables
4. Run the bot: `python bot.py`

---

### ⚙️ Usage

Interact with the bot using the following commands:

* `/login <username> <password>`: Log in to your account
* `/upload`: Upload a file
* `/list`: See your uploaded files
* `/download <file_name>`: Download a file
* `/rename <old_name> <new_name>`: Rename a file
* `/delete <file_name>`: Delete a file
* `/metadata <file_name>`: Get file metadata
* `/storage`: Check available storage
* `/logout`: Log out from your account
