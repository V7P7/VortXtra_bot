### 🚀 Features

* ✅ **Login and authentication** using username and password
* ✅ **File upload and management** with support for documents, photos, and videos
* ✅ **File renaming and deletion**
* ✅ **Metadata retrieval** for uploaded files
* ✅ **Storage information** with disk usage and available space
* ✅ **Inline query support** for easy command suggestion
* ✅ **Customizable commands** for login, upload, list, download, rename, delete, and more

### 📦 Installation

1. Install the required packages using `pip install -r requirements.txt`
2. Set up your Telegram bot using the BotFather
3. Create a `.env` file with your bot token and other environment variables
4. Run the bot using `python bot.py`

### ⚙️ Usage

* Start the bot and use the `/start` command to access the main menu
* Use the `/login` command to authenticate with your username and password
* Upload files using the `/upload` command
* Use the `/list` command to view your uploaded files
* Use the `/download` command to download a file
* Use the `/rename` command to rename a file
* Use the `/delete` command to delete a file
* Use the `/metadata` command to retrieve file metadata
* Use the `/storage` command to check disk usage and available space
* Use the `inline` feature to search for commands and files
